# ServerSideItems

**server-side mod** - only the host needs it installed.

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/E1E71PHUJ2)

## Item Changes

Each change can be turned off in the config.

- **Newly Hatched Zoea**: instead of summoning void creatures, you become Voidtouched. Every 5 (-25% per stack) seconds, fire 3 (+2 per stack) nullifying bombs that immobilize enemies and deal 300% damage. Auto-targets the strongest grounded enemy. Corrupts all yellow items.
- **Shatterspleen**: its explosion is based on the enemy's health without items, so enemies with health items don't make it much stronger.
